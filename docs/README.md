## IRIS GL manuals

SGI's Graphics Library Programming Guide, Reference Manual, Technical Reference, and IRIS GL to OpenGL Porting Guide are kept in the separate [sgi-docs](https://github.com/sgi-demos/sgi-docs) repository (moved there on 2026-09-05). The same manuals are archived at [bitsavers](https://bitsavers.org/pdf/sgi/) and the [Internet Archive](https://archive.org/search?query=silicon+graphics+graphics+library). That repository's `scripts/docs2md.sh` flattens the HTML Technical Reference into a single Markdown file for searching.
