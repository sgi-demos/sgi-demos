# Newave

SGI, late 1980s. A wave surface on a grid with a spinning light. Nothing in the source or on the tape names an author or a target machine. The wave starts flat: right-click, edit, then go.

## Provenance

Source is `sgi/newave` from the IRIS 4D demo tape as archived at bitsavers (sgidemos.tar.Z; hash in the [source archives table](../../docs/COPYRIGHT.md#8-source-archives)). 9 changed lines: three K&R float-pasting expressions (`NRAMPE.0-NRAMPB.0`) spelled out, each commented in place.
