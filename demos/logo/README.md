# Logo

Thant Tessman, SGI, July 1987 ("three days and much ugly hacking"). The SGI cube logo built from 1,296 quadrilaterals each frame, with two hardware lights and z-buffering. The demo-tape slide is in [logo.info](logo.info).

## Provenance

Source is `sgi/logo` from the IRIS 4D demo tape as archived at bitsavers (sgidemos.tar.Z; hash in the [source archives table](../../docs/COPYRIGHT.md#8-source-archives)), restored against that copy in 2023. 3 changed lines: one float-pasting macro (`JOINT.0`) spelled out.
