# Jello

Thant Tessman, SGI, August 1987. A real-time elastic-body simulation: an icosahedron of 13 masses joined by springs, integrated each frame, bouncing with a halftone shadow. The demo-tape slide is in [jello.info](jello.info).

## Provenance

Source is `sgi/jello` from the IRIS 4D demo tape as archived at bitsavers (sgidemos.tar.Z; hash in the [source archives table](../../docs/COPYRIGHT.md#8-source-archives)), restored against that copy in 2023. 12 changed lines: a missing return and a pointer-typed parameter for modern C.
