# Twilight

Howard Look, SGI, 1991. A background that looks like the twilight sky: a color gradient with 2,500 small stars and a scattering of large ones.

## Provenance

The source was taken from [a GitHub gist](https://gist.github.com/slacy/5ec0b38e8fe4da52f40e) posted by slacy in February 2015 (hash in the [source archives table](../../docs/COPYRIGHT.md#8-source-archives)); the repo copy differs from it by about 30 lines of modern-C fixes (int color arrays for `c3i`, prototypes, globals). The program's own header gives its origin: Howard Look at SGI, 1991 to 1992, built with `cc twilight.c -lgl_s -lm`. Its precursor is `night`, Look's 1990 sunset background that circulated on Usenet with a run of community enhancements (Trevor Paquette, Reuel Nash, and David Tristram of Electropaint, among others), preserved in [another gist](https://gist.github.com/sgi-demos/f90c37b0ae2bc1cdbf22e67196c3e4dc); night is not in this repository. The [IRIXNet thread](https://forums.irixnet.org/thread-3880.html) where both surfaced has the discussion.
